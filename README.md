📌 Overview
This repository contains my submissions for the CSE0001 Digital Literacy Project. As a Student Digital Ambassador, I completed five tasks designed to build awareness, professional presence, and safe online practices.

📝 Task 1 – Digital Literacy Awareness Infographic
- Tool Used: Canva
- Output: One-page infographic explaining digital literacy, useful tools, safe internet practices, professional online presence, and email etiquette.
- Reflection: I found it challenging to condense information into short points, but it taught me the importance of clear visual communication.

📝 Task 2 – Student Digital Portfolio
- Platforms Chosen: GitHub, LinkedIn, Kaggle
- Output:
- GitHub profile README with name, branch, year, and learning goal
- LinkedIn profile updated with education details
- Kaggle profile set up for data science practice
- Reflection: Each platform highlights different aspects of my academic and professional journey.

📝 Task 3 – Professional Communication & Social Media Etiquette
- Output:
- Two professional emails:
- Requesting an extension from a professor
- Expressing interest in a summer internship
- Social Media Do’s and Don’ts checklist (5 Do’s, 5 Don’ts)
- Reflection: Learned how poor communication online can cause real problems and the importance of maintaining a respectful digital footprint.

📝 Task 4 – Cybercrime Awareness
- Case Study: Phishing attack scenario (200–250 words)
- Prevention Checklist: 8 actionable tips for students, including UPI safety and reporting channels (cybercrime.gov.in, Helpline 1930)
- Reflection: I was surprised by how realistic phishing websites look. I will now avoid clicking links directly from emails.

📝 Task 5 – Final Reflection
- Output: Consolidated project report summarizing all tasks.
- Reflection: This project improved my awareness of digital tools, professional presence, and online safety. I now feel more confident guiding peers in responsible digital practices.
